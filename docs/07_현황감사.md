## 3. 최근 변경 요약 (2026-09)

**챗봇 답변 품질** (`349ec84`)
- 커버리지 엔진(`lib/chat/question-coverage.ts`) — 이력서에 근거가 있는 질문만 추천. `DEFAULT_SUGGESTED_QUESTIONS` 무조건 노출 제거
- 꼬리질문을 같은 근거로 검증하고 미달 시 커버리지 질문으로 교체. 직전 답변이 거절이면 2차 Gemini 호출 생략
- `chat_messages`에 답변 성공 여부·질문 출처·주입 종류·모델 계측

**프로필 삭제 · AI 사용량** (`40894de`)
- 프로필 삭제 UI 연결 + 행 삭제 전 Storage 정리 (고아 파일·공개 URL 잔존 방지)
- Gemini `usageMetadata` 실측 캡처 → 토큰 컬럼 저장. 프로필 단위 호출 카운터(Redis) 신설
- `rateLimitKey`/`rateLimitBucket` 추출 — 쓰기(`assertRateLimit`)와 읽기(대시보드)가 같은 키를 쓰도록 고정

**메인페이지 · 대시보드 UI 개편** (`40894de`)
- 랜딩: 대본 기반 Hero 챗봇 데모(실호출 없음), 스크롤 등장, 제품 사실 기반 통계 카드
- 대시보드: 공개 주소·복사·공개 토글을 상시 고정 바로 분리, 종합 개요 위젯 신설, 모바일 탭을 Select로 전환

**디자인 커스텀 시스템** (`a9a5362`)
- `profiles.theme_config` + 테마 프리셋 5종. `PublicProfileBody` 한 곳에서 CSS 변수를 덮어 하위 컴포넌트 무수정 적용
- 디자인 탭 + 전체 화면 편집 모드. 미리보기는 실제 공개 컴포넌트를 렌더
- **기존 버그 수정**: `--font-sans`가 자기 자신을 참조해 Geist가 적용된 적이 없었음 → Pretendard를 앱 기본 글꼴로 연결

## 6. 미적용 마이그레이션 ⚠️

working tree는 깨끗하지만 **DB에 반영되지 않은 마이그레이션이 3개** 남아 있을 수 있습니다.
적용 전에는 해당 기능이 런타임에서 실패합니다.

| 파일 | 미적용 시 증상 |
| ---- | -------------- |
| `20260918100000_chat_quality_metrics.sql` | 채팅 저장 실패 (답변 계측 컬럼 없음) |
| `20260919100000_chat_token_usage.sql` | 채팅 저장 실패 (토큰 컬럼 없음) |
| `20260920100000_profile_theme_config.sql` | 디자인 탭 저장 실패 (데모 탭은 정상) |

```bash
npm run db:push
npm run db:types    # 손으로 넣은 컬럼과 대조 — 아래 참고
```

> `types/database.ts`는 생성물이지만, 로컬 DB 없이 작업하느라 `chat_messages`의
> `answer_status`/`injection_kind`/`model`/`origin`/`input_tokens`/`output_tokens`,
> `system_prompts.coverage`, `profiles.theme_config`를 **손으로 추가**했습니다.
> `db:types` 재생성 후 diff가 없어야 정상입니다.

**수동 확인이 남은 항목**
- 디자인 탭 저장 → `/@slug` 공개 페이지 반영, 다크모드 가독성
- 채팅 1회 → 통계 탭에서 오늘 호출 수 증가 + 실측 토큰 적재
- 프로필 삭제 → Storage `{profileId}/` 폴더가 비는지
