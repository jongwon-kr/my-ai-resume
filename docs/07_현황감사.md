### 6-1. Gemini 모델 선택 env 기반 리팩터

| 파일 | 변경 |
| ---- | ---- |
| `lib/chat/constants.ts` | 하드코딩 모델 배열 제거 → `GEMINI_MODEL`(기본 1개) + `GEMINI_MODELS`(선택·fallback 목록), `formatGeminiModelLabel()`, `isAllowedChatModel()` 추가. `GEMINI_MODEL_CHAIN`은 deprecated alias |
| `components/public-profile/chat-panel.tsx` | `<Select>` 항목을 `GEMINI_MODELS`에서 렌더, 초기값 `"auto"` → `GEMINI_MODEL` |
| `lib/chat/handle-chat-request.ts` | 요청 body의 `model`을 허용 목록으로 검증, 미허용 시 `GEMINI_MODEL` |
| `next.config.ts` | `env`로 `GEMINI_MODEL`/`GEMINI_MODELS`를 클라이언트에 노출 |
| `.env.local.example` | 위 두 변수 문서화 |

**마무리 전에 결정할 것:**

1. **기본값이 `auto`가 아니라 특정 모델** — 방문자 채팅의 기본 경로에서 fallback 체인이 동작하지 않습니다. 기본 모델이 429/404면 그대로 에러 메시지가 나갑니다. 의도한 것인지 확인 (원복하려면 `chat-panel.tsx`의 `useState(GEMINI_MODEL)` → `useState("auto")`).
2. **모델 ID 실존 확인** — 기본 목록의 `gemini-3.5-flash-lite`, `gemini-3.1-flash-lite`, `gemini-3-flash`가 실제 사용 가능한 ID인지 AI Studio에서 확인. 없는 ID는 404이고, 1번 때문에 fallback도 안 걸립니다.
3. **`next.config.env`는 빌드 타임 인라인** — Vercel에서 값만 바꿔도 재배포해야 반영됩니다. 런타임 변경이 필요하면 `NEXT_PUBLIC_` 접두사 방식으로 옮기세요.
4. **모델 선택 UI가 공개 프로필(방문자)에 노출** — 방문자가 모델을 고를 수 있는 게 의도인지. 비용/쿼터 관점에서는 소유자 미리보기·모의 면접에만 두는 편이 안전합니다.
5. `GEMINI_MODEL_CHAIN` alias는 현재 import하는 곳이 없습니다 — 삭제 가능.
